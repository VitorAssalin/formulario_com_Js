Repositório dedicado ao desenvolvimento de um formulário de **Cadastro de Aluno**, criado como projeto prático para a faculdade. O objetivo é estudar a integração e manipulação do **JavaScript** em páginas estruturadas com **HTML5**, **CSS3** e estilizadas com **Bootstrap**.

> 🎓 **Propósito de Estudo:**  
> O foco principal do projeto é aplicar na prática a validação de formulários do lado do cliente (*client-side*), manipulação de elementos do DOM (Document Object Model) e eventos com JavaScript.

---

## 📌 Conteúdos Praticados

- **Estruturação Web:** Criação de layout responsivo utilizando elementos semânticos do HTML5 e componentes do Bootstrap 5.
- **Manipulação do DOM:** Captura de elementos e alteração de conteúdo dinamicamente (`document.getElementById`, `innerHTML`).
- **Escuta de Eventos:** Tratamento de envios de formulário com `addEventListener` e prevenção de comportamento padrão (`event.preventDefault()`).
- **Validação de Dados:** Uso de Expressões Regulares (**Regex**) e condições para validar campos de texto, RA (números) e critérios de segurança para senha.

---

## 🛠️ Ferramentas Utilizadas

- **Linguagens:** HTML5, CSS3 e JavaScript (ES6+)
- **Framework Front-end:** Bootstrap 5.3 & Bootstrap Icons
- **Editor de Código:** Visual Studio Code (VS Code)
- **Controle de Versão:** Git & GitHub
